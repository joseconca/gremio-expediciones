# Tier 2 Explorador — brief y contrato raster

## Identidad
Evolución de Arquero centrada en viaje, exploración y supervivencia. Diferenciar de Cazador: ropa más clara y ligera, chaleco de viaje arena, bufanda verde azulado, capa corta, botas de caminante y bolsas para suministros/mapas. La mujer tiene una trenza lateral para una silueta distinta; el varón lleva pelo corto bajo una prenda de viaje abierta, no una capucha cerrada.

## Restricción de capas
Las dos manos deben quedar vacías. No dibujar arco, carcaj, flechas, dagas, espadas ni otra arma dentro del cuerpo. Solo bolsos, correas, hebillas y prendas; las armas se añadirán mediante capas independientes.

## Contrato de salida
Másteres raster PNG de 256×384 (4 columnas × 3 filas: Idle, Caminar, Recibir daño) para ambos sexos. El workflow generará tiras PNG, frames nativos 32×64, previews y QA JSON. Fondo/residuos se pueden pulir tras revisión. No integrar a runtime sin aprobar las seis tiras.

## Estado
Generador raster en curso. Esperar a la ejecución de GitHub Actions para verificar las seis tiras y marcar el paquete generado.
